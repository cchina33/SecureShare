本サービスはプライバシーとセキュリティを最大限に尊重した設計ですが、健全な運用の維持のため、以下の行為を禁止しています：

プライバシー＆セキュリティポリシー

ゼロナレッジ・エンドツーエンド暗号化（Zero-Knowledge E2EE）
SecureShare は利用者のプライバシー保護を最重要視しています。送信データはお使いの端末（ブラウザ）内で暗号化され、復号鍵はサーバーに送信されないため、運営者を含め誰も平文の内容を閲覧できません。

1. 基本理念

SecureShare（以下「当サービス」）は、パスワード、機密メモ、画像を安全に共有するためのオープンソースWebアプリケーションです。当サービスは設計段階からのプライバシー保護に基づき設計されており、不要な個人情報の収集を一切行いません。

2. ゼロナレッジ暗号化の仕組み

当サービスでは、ブラウザ標準の Web Crypto API（AES-256-GCM 方式） を採用しています。

  • 端末内暗号化: 送信ボタンを押した瞬間、データはお手元の端末内で暗号化されてからサーバーへ送信されます。
  • 復号鍵の非送信: データを復号するための鍵は、共有URLのハッシュフラグメント（#<Key>）にのみ格納されます。ハッシュ部はHTTPリクエストとしてサーバーに送信されない仕様のため、サーバー管理者は復号鍵を取得できません。

3. サーバーで保管するデータ

当サービスのサーバー（Cloudflare D1 / R2）に一時保管されるのは、以下の最小限のデータのみです。

  • 暗号化されたデータ本体（平文は保存されません）
  • 有効期限日時および消去モード情報（期限管理用）
  • 閲覧回数フラグ（ワンタイム消去判定用）
  • ※ ユーザー登録機能は設けておらず、氏名・メールアドレス・電話番号等の個人情報は一切取得・保管しません。

4. データの破棄と自動削除ポリシー

当サービスに預けられたデータは、以下のルールに基づいて確実に削除されます。

  • 閲覧後に即時消去: 受信者がデータを開いて復号に成功した直後に、サーバーから完全に削除されます。2回目以降のアクセスは404となり、復元は不可能です。
  • 期限まで保持: 指定された有効期限（最大30日、画像は最大8日）が経過した時点で、自動的に物理削除されます。
  • 二重のセーフティネット: 未閲覧のまま放置された画像データも、オブジェクトストレージ（Cloudflare R2）のライフサイクルルールにより9日以内に強制削除されます。

5. 外部サービスおよびアクセスログ

サービスの安定運用および悪意あるDoS攻撃・自動ボットから防御するため、以下の技術を利用しています。

  • Cloudflare Turnstile: 自動化スクリプトを遮断するため、人間によるアクセスかどうかの検証に Turnstile を利用しています。
  • インフラログ: サーバー攻撃の検知および遮断の目的で、一時的なインフラアクセスログ（IPアドレス、ブラウザのUser-Agent等）が生成される場合がありますが、これらは共有された暗号化データと結びつけられることはありません。

6. Cookieおよびトラッキング

当サービスでは、利用者の行動追跡（トラッキング）やターゲティング広告配信を目的とした Cookie は一切使用していません。

7. 免責事項とお問い合わせ

当サービスはオープンソースとして無償で提供されています。細心の注意を払って設計・運用されていますが、ネットワーク障害や不可抗力によるデータ消失等の損害について保証するものではありません。

また、Cloudflare無料枠の上限に達した場合、新規受付を一時停止します。その場合既存の共有データは閲覧できなくなる可能性があります。

ご意見、脆弱性の報告、お問い合わせは日本語で GitHub リポジトリ より受け付けています。

8. ポリシーの変更について

本プライバシーポリシーは、サービスの改善や法規制の変更に伴い、予告なく改訂されることがあります。
