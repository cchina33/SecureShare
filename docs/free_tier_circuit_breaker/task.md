# タスクリスト: Cloudflare D1 / R2 無料枠サーキットブレーカー

Cloudflare D1およびR2の無料枠超過を防ぎ、上限に近づいた際にサービスを一時停止（HTTP 503）し、無料枠リセット（毎日00:00 UTC / 毎月1日00:00 UTC）時に自動再開するサーキットブレーカー機能を実装します。
