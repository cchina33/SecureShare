# 修正内容の確認 (Walkthrough): プライバシーポリシーモーダルの追加

## 概要
SecureShare の信頼性と透明性を高めるため、フッターに「プライバシーポリシー」のリンクを設置し、クリック時に画面遷移なしでポリシーを閲覧できるモーダルウィンドウを実装しました。

## 主な変更点

### 1. プライバシーポリシー内容の策定
ユーザーが安心してパスワードや機密画像を共有できるよう、以下の項目を明記しました：
- **ゼロナレッジ・エンドツーエンド暗号化（Zero-Knowledge E2EE）**: ブラウザ標準の Web Crypto API (AES-256-GCM) による端末内暗号化と、復号キー（`#` フラグメント）がサーバーに送信されない仕組み。
- **一時保管データ**: 暗号化データ、有効期限、閲覧回数フラグなどの最小限データのみで、氏名やメールアドレス等の個人情報は取得しないこと。
- **データ消去ポリシー**: 「ワンタイム即時物理削除」「期限切れ自動削除」「R2ライフサイクル9日自動削除」。
- **外部サービス・アクセスログ**: Cloudflare Turnstile による人間判定と、インフラセキュリティ目的の一時ログ。
- **Cookie・トラッキング**: 広告・追跡Cookieの不使用。
- **免責事項・お問い合わせ**: GitHubリポジトリへのリンク。

### 2. デザイン & スタイリング (`public/assets/css/style.css`)
- **ダークテーマ調和**: 既存の CSS 変数（`--bg-card`, `--border-color`, `--accent-primary` 等）を活用し、サービス全体と統一感のある洗練された外観。
- **背景ブラー効果**: `backdrop-filter: blur(5px)` により背景をぼかしてモーダルへの集中度を向上。
- **アニメーション**: 開閉時に滑らかなフェードイン＆スケールアップ（`cubic-bezier`）。
- **レスポンシブ**: スマートフォンなど画面の小さい端末でも最大高さ `85vh` で内側がスムーズにスクロールする設計。
- **フッターリンク**: 目立ちすぎずアクセスしやすい配置とホバーエフェクト。

### 3. HTML構造の追加 (`public/index.html`, `public/view.html`)
- フッターに「プライバシーポリシー」ボタントリガーと「GitHub」リンクを配置。
- アクセシビリティに配慮したモーダルマークアップ（`role="dialog"`, `aria-modal="true"`, `aria-labelledby="privacy-modal-title"`）。

### 4. モーダル制御スクリプト (`public/assets/js/privacy-modal.js`)
- モーダルを開いた際の背面スクロールロック（`document.body.style.overflow = 'hidden'`）。
- 閉じるボタン（ヘッダー×ボタンおよびフッター「閉じる」ボタン）での閉鎖。
- 背景オーバーレイ（外側）のクリックで閉じる機能。
- キーボードの `Escape` キー押下で閉じる機能。
