# 実装計画: プライバシーポリシーモーダルの追加

## 1. 目的と背景
SecureShare は「ゼロナレッジ・エンドツーエンド暗号化（Zero-Knowledge E2EE）」をコア価値とするセキュリティサービスです。
ユーザーがパスワードや機密画像などの極めてセンシティブなデータを安心して送受信できるよう、データがどのように暗号化・保護・破棄されるかを明記したプライバシーポリシーをフッターから閲覧可能なモーダルウィンドウ形式で実装します。

## 2. 実装方針
- **モーダルウィンドウ形式（離脱防止）**: 画面遷移（ページリロード）を発生させず、作成中のフォーム入力内容や復号画面の状態を維持したままポリシーを閲覧・確認できるようにします。
- **統一されたデザイン**: 既存のダークテーマ（CSS変数）、角丸、カードデザインと調和させ、視認性の高いレイアウトにします。
- **アクセシビリティ & UX**:
  - 右上の閉じるボタン（×）
  - モーダル外側（背景オーバーレイ）のクリックで閉じる
  - キーボードの `Esc` キー押下で閉じる
  - スマートフォン表示時の最大高さ指定とスムーズな縦スクロール

## 3. プライバシーポリシーの構成内容
1. **はじめに (基本方針)**: 本サービスが利用者のプライバシーとデータの安全性を最優先に設計されていること。
2. **ゼロナレッジ・エンドツーエンド暗号化**:
   - Web Crypto API (AES-256-GCM) による端末内暗号化。
   - 復号鍵は受取用URLのハッシュフラグメント（`#` 以降）にのみ含まれ、サーバーには一切送信されないこと。
   - 運営者を含め、第三者が中身を平文で閲覧することは技術的に不可能であること。
3. **一時保管されるデータと取り扱い**:
   - サーバーに保管されるのは暗号化データ、有効期限、消去モード等のメタデータのみ。
   - ユーザーの個人情報（氏名、電話番号、メールアドレス等）の登録・収集は行わないこと。
4. **データの自動削除と保持期間**:
   - 「閲覧後に即時消去」: 復号成功時にサーバーおよびストレージから直ちに物理削除。
   - 「期限まで保持」: 設定された有効期限の経過後に自動的に物理削除。
   - 画像ストレージ (Cloudflare R2) の最大8日間制限および二重の自動消去（ライフサイクルルール）。
5. **外部サービス・アクセスログ**:
   - ボット・DoS攻撃対策としての **Cloudflare Turnstile** の利用。
   - サービス運用および攻撃遮断を目的とした一時的なインフラログ（IPアドレス、アクセス日時等）。
6. **Cookieおよびトラッキング**:
   - 広告配信や外部トラッキングを目的とした Cookie は一切使用しないこと。
7. **免責事項・お問い合わせ**:
   - 免責事項および GitHub リポジトリ（Issue）での連絡受付。

## 4. 変更対象ファイル
- `public/assets/css/style.css`: モーダル用のCSSクラス（`.modal-overlay`, `.modal-content`, `.modal-header`, `.modal-body` 等）およびフッターリンクのスタイリング
- `public/index.html`: フッターへのリンク追加、モーダル要素の配置
- `public/view.html`: フッターへのリンク追加、モーダル要素の配置
- `public/assets/js/privacy-modal.js`（または各JS内）: 共通のモーダル制御処理（開閉、Escキー対応）

## 5. 検証手順
1. `index.html` および `view.html` でフッターの「プライバシーポリシー」リンクをクリックし、モーダルが正しく開くことを確認。
2. 閉じるボタン、背景クリック、Escキーのそれぞれでモーダルが閉じることを確認。
3. モバイル端末サイズでの表示崩れがないこと、スクロールが正常に機能することを確認。
